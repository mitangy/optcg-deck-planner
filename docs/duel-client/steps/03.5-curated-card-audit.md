## Goal

Ship a **fidelity patch** so every curated real id on the happy path matches its printed English identity (number, name, cost, power, counter, encoded keywords), implement ST01-001’s Activate:Main within the existing DON!! attachment model, regenerate the mobile atlas, and polish intent labels so the Expo board is playable with recognizable cards — **without** inventing unsupported effects.

Success looks like: `npm run sim` / rules tests green on the corrected set; `export-atlas` shows Guard Point / Chopper / Karoo etc.; a duel view never claims Jet Pistol draws cards; ST01-001 can give a rested DON!! once per turn via a legal intent.

## Decisions locked

| Topic | Decision | Rationale |
|-------|----------|-----------|
| Primary defect | Content audit + rewrite of curated defs | Silent house rules are worse than fewer cards |
| Unsupported prints | **Omit** (or never encode as a different effect) | ADR-010 / Step 3 keyword budget |
| ST01-001 | **Implement** Activate:Main once/turn: attach up to 1 **rested** cost-area DON!! to Leader or own Character | Matches print; reuses attachment model; fills the named Step 3 gap |
| Thousand Sunny | **Omit** until Stage Activate:Main exists | Do not keep false passive buff |
| Main-draw event | **Omit** until a print maps 1:1 to `mainDraw` only | Jet Pistol must not stay as draw |
| Counter event | Keep **ST01-014 Guard Point** as `counterPowerBonus: 3000` | Accurate print mapping to existing hook |
| Trigger draw fixture | **Omit** fabricated Law; drop `triggerDraw` from default decks unless a correct print is added later | Honesty over coverage |
| Replacement characters | Prefer **textless** ST01 vanillas: Karoo, Robin, Vivi (+ Chopper Blocker) | Finite set that still exercises curve/Blocker/Counter |
| Client | Atlas-aware `intentLabel`; optional hand-filter already present — no local rules | Board remains dumb |
| Protocol | **No wire change** unless a new intent type is required (see below) | Prefer reuse; if new intent type lands, bump docs only (still `protocolVersion: 1` envelope) |

### New intent (rules + protocol copy)

```ts
{ type: "activate_leader"; targetId: InstanceId } // attach 1 rested DON!!; once per turn
```

- Legal only in Main, active seat, leader is ST01-001 (or defs with `leaderActivateGiveRestedDon: true`), once per turn flag on `PlayerState`, target is own Leader or Character, ≥1 rested DON in cost area.
- Events: reuse `don_given` (or add `leader_activated` if clearer for clients — prefer reuse).
