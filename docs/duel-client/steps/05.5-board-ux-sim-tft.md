## Goal

Make the browser duel board **read like OPTCG Sim** (correct zone placement for board / hand / DON!!) and **feel like a polished auto-battler HUD** (TFT-inspired chrome), without changing rules or wire protocol.

Success looks like: a desktop browser match shows a playmat with labeled zones matching Sim/paper, DON!! in a cost strip, hand on a bottom rail, and gold/arena chrome that survives ~375px and ~1200px.
