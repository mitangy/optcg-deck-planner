# pr-assets (never merge)

Screenshots and recordings for PR bodies live here, not in the code.
This branch has no shared history with `main` and must never be merged.

- One folder per PR or issue: `<number>/<file>` (use the issue number if the PR doesn't exist yet).
- Embed with a commit-pinned raw URL so the image keeps working:
  `https://raw.githubusercontent.com/mitangy/optcg-deck-planner/<commit-sha>/<number>/<file>`
- How to upload: see "PR screenshots and recordings" in `CLAUDE.md` on `main`, or run
  `tools/pr-assets/upload.sh <number> <files...>` from a checkout of `main`.
